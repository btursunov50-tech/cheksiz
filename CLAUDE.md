## Lessons learned
- Videos/posts the owner sends to learn from: the owner sends them so Claude gets stronger and finds new services. For each one: (1) say what it is, (2) check the claims against sources, (3) compare with what we already have and the owner's earlier ideas, (4) say what it gives us (a service to sell, a content idea, a tool, or nothing) and the next step. Then log it in `ideas/IDEAS.md`. Look for new services built from what we already have.
- `/top`: web search rejects `user_location` with country `UZ`, so leave it out. Offer bots to high-message businesses (cafes, salons, clinics, courses, chains). For low-volume, high-value shops (furniture) offer a catalog, Google Maps or photos. Never pitch a bot as a replacement for the manager. Drafts link the bot demo and the Infinite site, not B-Trend.
- Decisions (owner, 2026-10-14): don't push `/top` outreach (businesses the bot finds online are already digital, so it costs money without bringing clients) and don't suggest paid tools such as Postiz until there are more clients. Prefer free tools.
- Telegram bots cannot message anyone first. Outreach is sent by the owner from their own account, 2–3 a day, during business hours.
- Videos: original scenes cut at 6/14/22 s. In scene 3 the cartoon girl speaks twice (about 14.5–16.6 s brand name, then 18–21 s call to action). The old English subtitles are removed by inpainting only the letters (OpenCV), not with boxes or blurred strips. Music: Uzbek/Russian use "Dutar's Whisper" (the owner made it himself with AI, so no Content ID risk) from 3:17, English uses "SMART wallpaper" from 0:07, ducked under the voice.
- This cloud environment cannot reach many hosts (the Vercel site, TTS services, Hugging Face). Ask the owner to check live pages, and use files they upload.
- Before starting work, fetch `origin/main`: the owner also works from other sessions.
- Short videos (see `video/README.md`): Claude cannot hear audio and this environment has no Uzbek TTS/STT. Give the owner the voice text, they make the voice elsewhere; ask for one file per sentence, or align scenes by pauses and syllable counts, then ask the owner to check sync. Every video ends with the owner's avatar for 3 s (`video/avatar.mp4`, with a question plate such as "Siz-chi? … Izohga yozing!") and then the 4 s vertical end card (`video/end_uz.html`/`_ru`/`_en`): a red "OBUNA BO'LING" button and, under it in gold, the bot (@sahiychishopbot), the site and @Boxo_xxxx. The owner asked for the avatar on every video; don't forget it. Music sits under the voice (sidechain ducking), not too quiet. Blur names/IDs in screenshots. YouTube gets a clean video plus uz/ru/en `.srt`; Instagram/Facebook get Russian subtitles burned in; LinkedIn gets English burned in and a "how I made it with AI" post. Don't put real people's AI faces or voices in videos.
- Cinematic style on every video (owner chose the **soft** version on 2026-10-11): run `video/cine.sh` on the base video before subtitles, and `video/sfx.sh` on the mixed audio, with the scene cut times. Clip sources: the owner finds Pexels/Pixabay footage generic and overused, so use AI clips (Claude writes Kling/Veo/Hailuo prompts, the owner generates them) and the owner's own footage. Never take clips from other people's YouTube/Instagram/TikTok videos (Content ID).
- Content mix (owner, 2026-10-13): AI videos are everywhere and "use our bot" videos get almost no views; many people fear AI because Telegram accounts and data get stolen. Make unusual videos that are useful or interesting on their own (stories, mini-dramas, trends, protecting people from scams, e.g. the voting-link code theft and Telegram's cloud password); trend video 1 (MrBeast) got ~1400 views in a day. Mention the bot only in the end card. Ask the owner for YouTube Studio / Instagram insights screenshots to compare videos, since Claude cannot open those sites here.
- Hooks: before giving a voice-over block, score the first line's English translation with `python3 .claude/skills/ig-reel/hookscore.py` (under 50 = weak; our first hooks scored 43–49) and offer a stronger one. Never invent facts (ages, numbers) to make a hook stronger.
- Voice-over prompts: always give ONE copyable block that starts with the voice settings (same adult male channel voice, Uzbek Latin, style, 1.0x speed, 1 s pause after each line, one WAV, no music, pronunciation notes such as "MrBeast" = "Mister Bist") followed by numbered lines with emotion and target length in brackets. Also show a table with the video timings. The owner pastes the block as is.
- Copyable prompts (images, video, voice, posts): every copy block must be complete and ready to paste as is. Never say "put this at the start of each prompt" or split a shared style part into a separate block: repeat the full style text inside every single prompt block, one block per prompt. The owner asked for this (2026-10-11).
- Image-to-video prompts (Veo/Kling): send each source image as its own file with that image's complete prompt inside the file caption (scene number, voice line, then the full prompt). Text written between file sends does not show under the images in the owner's app, so the caption is the only reliable place. Never list prompts in one place and images in another; the owner asked for this (2026-10-11).
- Posting guides: always put the full post texts (Telegram uz, YouTube title + description, Instagram/Facebook ru, LinkedIn en) inside the same message as the steps, links and file names, every time. Never refer back to texts in an earlier message; the owner asked for this.
- Posting guides, file per post (owner, 2026-10-14): send each video file with its full post text in the file caption, right after that post: uz file + Telegram text, en file + YouTube title/description + LinkedIn text, ru file + Instagram/Facebook text. When one file serves 2–3 posts, say so in the caption (e.g. "this file: YouTube + LinkedIn"). The `.srt` files go with the YouTube caption.
- Copy buttons (owner, 2026-10-15): file captions have no copy button in the owner's app, so in every posting guide also put each post text (and every prompt) in its own fenced code block in the chat message, one block per platform, so the owner copies with one tap instead of selecting text. Keep the file captions too.
